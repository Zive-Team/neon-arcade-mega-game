## Androidアプリインストール方法

まずapkをこのサイトからバージョンの数字が大きいやつをダウンロードしてください

つぎに以下の方法でinstallしてください。

```adb install neongame-[バージョン].apk```

を実行してインストールorスマホよりダウンロードし、ダウンロードフォルダからファイルをクリックし、インストールしてください。

動作確認済み端末及びバージョン
